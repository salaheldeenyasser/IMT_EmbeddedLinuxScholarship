# CPP Practice Exercises

This directory contains fundamental C/C++ practice exercises covering core programming concepts and techniques.

## Directory Structure

### 00_Miscellaneous
Basic practice exercises and utility functions:
- **PrintBinary**: Programs demonstrating binary representation and bit manipulation

### 01_Pointers
Foundational pointer concepts and operations:
- **Basics.cpp**: Introduction to pointer syntax, declaration, dereferencing, and pointer arithmetic

### 02_Structs
User-defined types using structures:
- **Basics.cpp**: Structure declaration, member access, initialization, and practical examples

### 03_Unions
Memory-efficient data structures using union types:
- **Basics.cpp**: Union definition, member access, and memory layout understanding

## Purpose

These exercises are designed to reinforce fundamental C/C++ concepts through hands-on practice. Each subdirectory focuses on a specific topic with simple, focused examples.

## Getting Started

1. Navigate to any subdirectory
2. Compile the source files using:
   ```bash
   g++ -o output filename.cpp
   # or for .c files
   gcc -o output filename.c
   ```
3. Run the compiled executable:
   ```bash
   ./output
   ```

## Topics Covered

- Binary representation and bit operations
- Pointer fundamentals and memory addresses
- Aggregate data types (structs)
- Union types and memory optimization
